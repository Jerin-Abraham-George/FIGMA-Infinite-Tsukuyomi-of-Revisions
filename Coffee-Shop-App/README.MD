# ☕ Coffee Shop Mobile App – UI/UX Design

## 📘 Overview
The **Coffee Shop App** is a simple mobile UI/UX prototype designed in **Figma** to provide a convenient experience for browsing coffee, selecting drinks, managing a cart, and placing orders.

---

## 🎯 Objectives
- To design a simple and intuitive coffee ordering experience.
- To create a clean, visually appealing mobile interface.
- To practice UI design and interactive prototyping in Figma.

---

## 🔑 Key Features
- **Home Screen:** Browse coffee and explore available drinks.
- **Product Details:** View coffee information, pricing, and customization options.
- **Shopping Cart:** Review selected items and manage quantities.
- **Checkout:** Select payment options and confirm orders.
- **Order Confirmation:** Display successful order placement and estimated delivery time.

---

## 🧰 Tools & Technologies
- **Figma** – UI/UX design and prototyping
- **Auto Layout** – Layout organization
- **Components** – Reusable UI elements
- **Prototype Interactions** – Screen navigation and transitions

---

## ✅ Result
The **Coffee Shop App** demonstrates a straightforward mobile ordering flow, taking users from browsing coffee to checkout and order confirmation through a consistent, user-friendly interface.
