# 🎨 Figma Design Portfolio

A curated collection of Figma design projects demonstrating UI/UX fundamentals — layout structuring, responsive design, typography, and component-based design systems.

## Overview

Each project applies core design principles to real interface problems, covering prototyping, user-flow creation, and reusable design systems for web and mobile.

## 🧠 Focus Areas

- UI layout structuring and responsive design
- Color theory, typography & component hierarchy
- Prototyping and user-flow creation
- Design systems & reusable components

## 🗂️ Repository Structure

- Individual folders for each design project
- Exported assets (`.png`, `.jpg`, `.svg`)
- Project previews and screenshots
- Documentation explaining design decisions

## 🛠️ Tools & Concepts

Figma (Frames, Auto-Layout, Variants, Components) · Prototyping & Interactions · Design Systems · Typography & Color Theory

## 🚀 Roadmap

Future additions will include micro-interactions, full design systems for SaaS/mobile products, accessibility-focused improvements, and case-study driven UX projects.
