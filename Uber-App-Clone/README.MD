# 🚕 Uber App Clone – Mobile UI/UX Design (Figma)

## 📘 Overview
The **Uber App Clone** is a complete **mobile UI/UX design project** created in **Figma**, replicating the core ride-hailing experience of a real-world cab booking application.

This project demonstrates a **map-centric user experience**, guiding users through authentication, ride booking, live ride tracking, payments, ratings, ride history, and account management — all structured using modern mobile UX patterns such as bottom sheets and step-based flows.

---

## 🎯 Objectives
- To design a **realistic end-to-end ride booking workflow**  
- To practice **map-based UX and location-driven interactions**  
- To implement **bottom-sheet navigation patterns** used in ride-hailing apps  
- To create a **developer-ready mobile UI system**  
- To simulate both **instant ride booking and ride joining experiences**

---

## 🔑 Key Features
- **Onboarding Experience:** Intro screen explaining seamless ride booking  
- **Authentication Flow:**  
  - Sign In & Sign Up screens  
  - Google Sign-in option  
  - Form-based validation layout  

- **Map-Based Home Screen:**  
  - Pickup & drop location input  
  - Interactive map background  
  - Ride search CTA  

- **Ride Selection:**  
  - Vehicle type selection  
  - Reserve ride option with quantity controls  

- **Ride Discovery & Matching:**  
  - Searching for rider screen  
  - Ride found confirmation state  

- **Live Ride Experience:**  
  - Driver profile, car number & PIN  
  - Rider list and ride participants  
  - Cancel ride option  

- **Payment Flow:**  
  - Visa & cash payment options  
  - Coupon code application  
  - Pay Now CTA  

- **Ride Status & Tracking:**  
  - Ride timeline (Requested → Arrived → Completed)  
  - Ride details with downloadable info & incident reporting  

- **Post-Ride Interaction:**  
  - Ride rating & review option  

- **Ride History:**  
  - Previous rides list with pricing & rider details  

- **Account Management:**  
  - Profile info  
  - Become a rider option  
  - Terms & conditions  
  - Secure sign-out
